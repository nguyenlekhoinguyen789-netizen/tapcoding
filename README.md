Just a fun project i do in my free time.
Here are some of the features:
-Adding any games/applications you want to limit using time(This can be done through adding the launcher or directly the game or the application)
-There is a focus clock which block out any distraction while you are working/studying which you can set at any time you like
-There will be a warning 5 minutes before you hit the usage limit so it is highly advice that you save any thing you are doing before the app close down
-If you want to add a bit more usage time for that specific date, there will be always a overdrive code( which is randomly generated everyday) for you to get more time
-The app cannot be closed if you don't have the code btw
-This is still a prototype so there will be bug if you find one you can report
-Also this is built using qt creator so make sure to download it before using
